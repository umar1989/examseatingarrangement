Exam Seating Arrangement

Add classes and rooms, pick a rule, generate, adjust, print.

1. Classes & exams

Give a roll-number range (prefix optional), and/or upload a CSV with columns roll,name,class. CSV rows are added to the class with the same name (created if missing). Each class can have its own exam, date and time.

2. Rooms & benches

Enter how many 2-seater and 3-seater benches each room has. A room can have both.

3. Arrangement rule

Locked seats (🔒) stay where they are when you re-generate. Changing a roll range or bench count clears the arrangement.

4. Seating plan

    Data is saved in this browser only (localStorage).
